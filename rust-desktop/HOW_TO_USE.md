## 1. Add PDFs — ဖိုင်ထည့်ပါ

အပေါ်က **Add PDFs** ကိုနှိပ်ပြီး `.pdf` ဖိုင်တစ်ခု သို့မဟုတ် အများအပြား ရွေးပါ။
ဖိုင်တွေကို app ထဲ ဆွဲထည့်နိုင်ပါတယ်။ ဘယ်ဘက် **Documents** စာရင်းမှာ ပေါ်လာပါမယ်။

**Shortcut:** `Ctrl+O`

## 2. Reading mode — ဖတ်မယ့်နည်း ရွေးပါ

- **Auto:** ပုံမှန်သုံးရန်။ စာသားပါတဲ့ PDF ကို တိုက်ရိုက်ဖတ်ပြီး scan စာမျက်နှာတွေကို OCR နဲ့ဖတ်ပါတယ်။
- **Force OCR:** စာသားပျက်နေတဲ့ PDF သို့မဟုတ် စာသားနဲ့ scan ပုံ ရောပါတဲ့ PDF အတွက် ရွေးပါ။ စာမျက်နှာအားလုံးကို OCR နဲ့ ပြန်ဖတ်ပါမယ်။
- **Text only:** PDF ထဲက စာသားကိုပဲ ထုတ်ပါမယ်။ Scan PDF အတွက် မသင့်တော်ပါဘူး။

ပထမဆုံး **Auto** နဲ့ စမ်းပါ။ စာသားမမှန်ရင် **Force OCR** ရွေးပြီး **Convert all** ကို ပြန်နှိပ်ပါ။

## 3. OCR language — ဘာသာစကား ရွေးပါ

**Myanmar + English** button ကိုနှိပ်တိုင်း **Myanmar → English → Myanmar + English** အစဉ်အတိုင်း ပြောင်းပါမယ်။
မြန်မာစာနဲ့ English ရောပါတဲ့ စာရွက်အတွက် **Myanmar + English** ကိုသုံးပါ။ Language ရွေးချယ်မှုက OCR ဖတ်တဲ့ စာမျက်နှာတွေကို သက်ရောက်ပါတယ်။

## 4. Convert all — စတင်ပြောင်းပါ

**Convert all** ကိုနှိပ်ပါ။ ဖိုင်နဲ့ စာမျက်နှာတစ်ခုချင်းစီရဲ့ progress ကို စောင့်ကြည့်နိုင်ပါတယ်။
ပြောင်းနေစဉ် mode/language ကို ပြောင်းလို့မရပါဘူး။ ရပ်ချင်ရင် **Cancel** ကိုနှိပ်ပါ။

**Shortcut:** `Ctrl+Enter`

## 5. Review — ရလဒ်ကို စစ်ပါ

ဘယ်ဘက်က ဖိုင်ကိုနှိပ်ပါ။ စာမျက်နှာတွေ ပြောင်းပြီးတာနဲ့ **SOURCE PDF** ဘက်မှာ မူရင်းပုံနဲ့ **MARKDOWN** ဘက်မှာ ထွက်လာတဲ့စာသားကို ယှဉ်ကြည့်နိုင်ပါတယ်။

- **← / →:** စာမျက်နှာ ပြောင်းကြည့်ရန်။
- **Source / Preview:** Markdown code နဲ့ ဖတ်လို့ရတဲ့ preview ကြား ပြောင်းရန်။
- **Copy page:** လက်ရှိစာမျက်နှာရဲ့ Markdown ကို copy လုပ်ရန်။

မြန်မာ OCR မှာ အမှားရှိနိုင်ပါတယ်။ စာသား၊ ကိန်းဂဏန်းနဲ့ နာမည်တွေကို မူရင်းနဲ့ ပြန်စစ်ပါ။
ဒီ version က tables/columns ပုံစံကို အပြည့် ပြန်မတည်ဆောက်နိုင်သေးပါဘူး။

## 6. Export — Markdown သိမ်းပါ

ဖိုင်ရဲ့ status **Done** ဖြစ်သွားရင် **Export** ကိုနှိပ်ပြီး သိမ်းမယ့် folder ရွေးပါ။
ရွေးထားတဲ့ PDF တစ်ဖိုင်လုံးရဲ့ စာမျက်နှာအားလုံးကို `.md` ဖိုင်တစ်ခုအဖြစ် သိမ်းပါမယ်။

**Export all** က ပြောင်းပြီးတဲ့ ဖိုင်အားလုံးကို သိမ်းပါတယ်။ မူရင်း PDF ကို မပြင်ပါဘူး။
ဖိုင်နာမည်တူ `.md` ရှိပြီးသားဆိုရင် `(1)`, `(2)` စတဲ့ နံပါတ်နဲ့ ဖိုင်အသစ် သိမ်းပါမယ်။

## 7. Activity — ပြဿနာရှိရင် စစ်ပါ

**Activity** ကိုနှိပ်ပြီး error နဲ့ လုပ်ဆောင်မှုမှတ်တမ်းတွေကို ကြည့်ပါ။
Password ခံထားတဲ့ သို့မဟုတ် ပျက်နေတဲ့ PDF တွေကို ဒီ version မှာ ပြောင်းမရနိုင်ပါဘူး။
Runtime missing လို့ပြရင် bundled runtime ပါတဲ့ installer နဲ့ ပြန်တပ်ဆင်ပါ။

## အသုံးဝင်တဲ့ buttons

- **Remove selected:** ရွေးထားတဲ့ဖိုင်ကို queue ထဲက ဖယ်ရန်။
- **Clear:** Queue ကိုရှင်းရန်။ ဒီနှစ်ခုက disk ပေါ်က ဖိုင်တွေကို မဖျက်ပါဘူး။
- **Dark / Light:** Theme ပြောင်းရန်။
- **How to use / F1:** ဒီလမ်းညွှန်ကို ပြန်ဖွင့်ရန်။ **Close**, အပေါ်က **×**, သို့မဟုတ် **Esc** နဲ့ ပိတ်နိုင်ပါတယ်။

ဖိုင်တွေကို ဒီစက်ပေါ်မှာပဲ ပြောင်းပါတယ်။ Conversion အတွက် internet သို့မဟုတ် API key မလိုပါဘူး။
